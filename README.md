# BookNook

AI-powered book discovery and visualization. Recommend books by mood, pacing, tone, and vibe. Explore 10,000+ books on an interactive semantic map.

**Live site:** https://mihikabairathi.github.io/book_nook/

## Features

- **Natural language search** — "something melancholy and slow set in Japan with beautiful prose"
- **Mood & vibe sliders** — dial in darkness, pacing, character focus, depth
- **UMAP book map** — every book as a point; similar books cluster together
- **Author network** — force-directed graph of stylistically similar authors
- **Publication timeline** — zoom from century to decade to year
- **Genre mood bubbles** — see which genres skew dark vs. cozy

## Running locally

```bash
cd pipeline
pip install -r requirements.txt
python 00_seed.py              # seeds ~500 books, runs full pipeline
python -m http.server 8000 --directory ../docs
```

Open http://localhost:8000

## Pipeline & data freshness

Data is generated by a Python pipeline and committed to `docs/data/`. GitHub Actions re-runs the pipeline monthly, pulling new books from Open Library and re-embedding everything.

See [CLAUDE.md](CLAUDE.md) for full pipeline documentation.

## Cost

Nearly free. The only cost is Claude Haiku for LLM labeling: ~$8.40 for the initial 10k-book run, then ~$0.17/month for new books.
